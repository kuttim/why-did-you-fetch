# Security

`why-did-you-fetch` patches `fetch`/`XMLHttpRequest` in the browser (and Node) apps that use it,
so a vulnerability here could affect every app that installs it.

If you find a security issue, please report it privately via
[GitHub Security Advisories](https://github.com/kuttim/why-did-you-fetch/security/advisories/new)
rather than opening a public issue. We'll get back to you as soon as we can.
